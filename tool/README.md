# BTT Rule Checker

`btt_check.py` enforces the strict Branching Tree Technique (BTT) rules for tests under `test/btt`.
It is designed to run locally and in CI.

## Usage

```bash
python3 tool/btt_check.py
```

Skip the `bulloak` check step (useful if `bulloak` is not installed):

```bash
python3 tool/btt_check.py --skip-bulloak
```

## What It Checks

1. **Bulloak compliance**
   - Runs `bulloak check test/btt/*.tree` (unless `--skip-bulloak`).

2. **No Bulloak separators**
   - Fails if any `BULLOAK AUTOGENERATED SEPARATOR` markers exist.

3. **README tree table sync**
   - Fails if `test/btt/README.md` is missing any `.tree` file entries
     or contains extra `.tree` entries.

4. **Tree leaf specificity**
   - Rejects vague leaves like `it should revert` without an explicit error.

5. **No bare `vm.expectRevert()`**
   - Requires explicit selectors or encoded selectors.

6. **BTT base class**
   - Abstract BTT test contracts must extend `BTTModifiers` or `StakerBTTModifiers`.

7. **Modifiers are setup-only**
   - Modifiers must not contain assertions or `expectRevert`.

8. **Tests must assert**
   - Each `test_` function must contain at least one assertion or `expectRevert`/`expectEmit`.

9. **No loops in tests**
   - Rejects `for`/`while` loops inside test bodies to preserve 1:1 leaf mapping.

## Exit Codes

- `0` if all checks pass
- `1` if any rule is violated

## Notes

- The checker uses lightweight parsing and regexes; if you see a false positive,
  ping the maintainers and we can refine the rule.
- Keep this in sync with `test/btt/README.md` rules.
